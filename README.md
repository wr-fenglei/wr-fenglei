# 你好, 我是煜畦 YuQi

这里放着我日常使用的 AI 表达规则和协作技能

### [AGENTS.md](https://github.com/wr-fenglei/agents.md)

我写这些规则, 是为了减少冗长难懂的回答和让人不舒服的套话, 让 AI 的意思容易读懂, 也方便对齐理解

如果你也想调整 AI 的回答方式, 可以从这里挑选适合自己的规则, 放进 `AGENTS.md`

### [口语化 · speak](https://github.com/wr-fenglei/speak) · 像 GPT-Live 那样交流

模仿 GPT-Live 自然的口语表达, 用准确的概括抓住重点, 帮你快速理解长文内容

### [导航者 · navigator](https://github.com/wr-fenglei/navigator) · 苏格拉底式提问与多 loop 协同

通过苏格拉底式提问, 帮你找到真正想解决的问题, 明确目标和解决方案

把方案拆成多个可验证的 loop, 由主 agent 担任管理者, 按依赖关系安排各个 loop 的执行和验证, 根据结果调整下一步, 自动推进直到满足验收标准
