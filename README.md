# 你好, 我是煜畦

这里记录我日常使用的 AI 表达规则, 会话协作方法和对话界面设计

### [AGENTS.md](https://github.com/wr-fenglei/agents.md)

我写这些规则, 是为了减少生硬的套话, 让 AI 按约定的用词和格式表达

如果你也想调整 AI 的回答方式, 可以从这里挑选适合自己的规则, 放进 `AGENTS.md`

### [会话协调者模板](https://github.com/wr-fenglei/agent-coordinator-template)

我用一个协调会话记录各负责会话的职责和项目, 接收任务, 转交并跟进, 各项目继续在对应会话中维护

这个仓库提供 `AGENTS.md` 模板, 包含协调职责, 会话索引和角色项目资料, 便于按职责找到负责会话, 并在项目变化时更新记录

使用前需核对宿主是否加载规则, 实际转交和跟进依赖宿主提供的会话工具, 填写后的真实会话标识和本机路径保留在本地

### [context-editor-ui](https://github.com/wr-fenglei/context-editor-ui)

面向对话交互的设计系统, 整理消息, 工具调用, 输入框, 上下文编辑和评审备注等共享组件及规范

可以通过组件页和集成示例查看结构与交互, 示例使用本地状态, 不向模型服务发送消息
