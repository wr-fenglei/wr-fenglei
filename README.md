# 你好, 我是 Fenglei

我在整理自己和 AI 一起做事的方法: 怎样把话说清楚, 怎样从一个想法开始, 一步步做到验收

目前主要维护这 3 个仓库, 你可以按需要选一个, 也可以一起用

### [AGENTS.md](https://github.com/wr-fenglei/agents.md) · 约定怎么表达

我日常使用的表达规则: 先说结论和重点, 用具体事实和动作解释, 删掉套话和没有依据的评价

如果你也想调整 AI 的回答方式, 可以从这里挑选适合自己的规则, 放进 `AGENTS.md`

### [口语化 · speak](https://github.com/wr-fenglei/speak) · 像当面交流一样回答

把口语化表达做成一个技能: 先用几句话说清答案, 再按需要展开, 追问时围绕当前问题回答

适合日常问答, 解释复杂内容和改写长文, 保留必要的事实, 条件和不确定性

### [导航者 · navigator](https://github.com/wr-fenglei/navigator) · 从想法推进到验收

通过提问明确目标和验收标准, 把方案拆成能实施, 能验证的步骤, 再协调执行, 根据结果调整下一步

适合需求讨论, 方案选择和任务执行, 简单任务直接做, 也可以只讨论目标或只拆解方案
